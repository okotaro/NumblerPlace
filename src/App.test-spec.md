# App.tsx 結合テスト仕様書

対象: `src/App.tsx`（Board・Controls・ClearModal・useNumberPlaceGame・useKeyboardControlsの結合）
関連仕様: `docs/spec.md` 全章、`docs/roadmap.md` フェーズ1 完了条件

New Gameから解答・メモ入力・Check・クリアまでの主要フローを、実際のDOM操作を通じて検証する。個々のコンポーネント・フックの詳細な振る舞いはそれぞれの `*.test.tsx`/`*.test.ts` で担保済みのため、ここでは「組み合わせたときに繋がって動くか」を確認する。
