# solver.ts テスト仕様書

対象: `src/services/backtracking/solver.ts`
関連仕様: `docs/roadmap.md` フェーズ3タスク1

自作バックトラッキング法によるパズル解法（`solve`）と解の一意性判定（`hasUniqueSolution`）を検証する。

## solve

| #   | ケース                                     | 前提・入力                                                                   | 期待される結果                                             |
| --- | ------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 1   | 一意な解を持つ盤面を正しく解く              | 既知の解答を持つ標準的なナンバープレース問題（Wikipediaの例題）を入力         | 既知の正解と一致する9x9の解答が返る                          |
| 2   | 既に全マス埋まっている正しい盤面            | 空欄のない有効な完成盤面を入力                                                | 入力と同じ盤面がそのまま返る                                 |
| 3   | 解答不能な盤面（矛盾あり）                  | 完成盤面の1マスを空欄にし、同じ行の別マスに重複する数字を入れて、その空欄マスがどの候補も置けない状態にした盤面 | `null` が返る                                                |
| 4   | 解答がヒント値と矛盾しない                  | 標準的な問題を入力                                                            | 返り値のうち元々ヒントだったマスの値は入力時の値と一致する   |

## hasUniqueSolution

| #   | ケース                             | 前提・入力                                                       | 期待される結果 |
| --- | ----------------------------------- | ------------------------------------------------------------------ | -------------- |
| 1   | 一意解を持つ標準的な問題            | Wikipediaの例題（1マスも余計に空いていない、公開されている問題）   | `true`         |
| 2   | 空欄のない完成盤面                  | 有効な完成盤面（空欄0個）                                          | `true`         |
| 3   | 空欄が多く解が複数存在する盤面      | 全マス空欄の盤面                                                   | `false`        |
| 4   | 矛盾があり解が存在しない盤面        | solveのケース3と同じ、候補が置けない空欄を含む盤面                | `false`        |
